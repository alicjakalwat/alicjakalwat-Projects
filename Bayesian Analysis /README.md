The aim of the project is to implement a Bayesian Hierarchical Model to analyze the housing market across the Home Counties in England.

It enabled to establish baseline price estimates for each county while also to capture how the impact of specific property characteristics varies geographically.
And since BHMs are conceptually similar to a frequentist Mixed Effects Models (MEMs), the study also compares the
results and interpretations of these two approaches, evaluating the specific advantages of adopting a Bayesian framework.
This study in general provides a powerful tool for real estate analysis, and offers a more nuanced understanding of local market dynamics than standard
global regression models.

The folder contains a PDF file with the STAN model code in the Appendix.
